# Exponential versus linear — draft pedagogical supplement

Source package: W4-G9-EXPO-MODELING, PR #328. Status DRAFT_UNVERIFIED; no runtime activation.

Observe: Two synthetic savings plans begin at 200 units. Plan A adds 20 units per year; Plan B increases by 10 percent of its current amount.
Predict: Commit a year-two estimate for each plan before revealing any table.
Manipulate: Construct labelled tables through repeated +20 and ×1.10 operations, with keyboard/text equivalence.
Explain: Both reach 220 after one year but year two is 240 versus 242. Identify the new reference base for the second percentage.
Practice: Vary initial values and exact rational multipliers with seed-separated guided questions.
Diagnose: Use the error pattern to choose a probe instead of a generic hint.
Transfer: A reserve starts with 320 units and loses 25 percent of the remaining amount each period. Predict two-period amount.
Verify: Compute 320 times (3/4) squared = 180; explain why subtracting 80 twice incorrectly holds the original reference fixed.

Wrong idea: Always take a percentage of the initial amount. Ask what the percent acts on after the first change. Rebuild the two-column table.
Wrong idea: Constant ratio means constant difference. Ask for the differences and ratios in 3,6,12,24; identify which pattern remains fixed.

The student should not see an answer key or a scaffold during unseen transfer. Independent assessment must be backend-scored only after Engineering acceptance and Muse verification. The tabular interaction is a proposal, not a claim of shipped UI.
