# Quadratic patterns — draft pedagogical supplement

Source package: W2-G9-QUADRATIC-PATTERNS, PR #328. Not approved, not active.

Observe: Build rectangle with sides n and n+2; count units at n=1,2,3.
Predict: Before adding the next border, predict the area at n=4 and explain why.
Manipulate: Partition into n squared and two length-n strips; use text descriptions as an alternative to tiles. This is an interface specification, not a completed manipulative.
Explain: Values 0,3,8,15 have differences 3,5,7 and second differences 2,2; n(n+2)=n squared +2n.
Practice: Expand seeded rectangle problems while keeping answer checks private.
Diagnose: Ask which observed response reveals a misunderstanding.
Transfer: Compare (x+2)(x+5) and (x+3)(x+4); both have x coefficient 7 but different constants.
Verify: At x=3 the first area is 40; check by independent expansion and multiplication.

Wrong idea: constant first differences. Probe every adjacent difference before concluding a linear rule.
Wrong idea: factoring uses only the sum. At x=0 test (x+1)(x+6) against x squared +7x+12; products must match too.
Wrong idea: x squared =36 has only positive root. Verify both positive 6 and negative 6, then distinguish algebraic real roots from positive length constraints.
