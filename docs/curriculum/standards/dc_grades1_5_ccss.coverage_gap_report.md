## The "0 unmapped" reading — read this before reporting anything

Zero unmapped means only that **every CCSS domain (OA/NBT/NF/MD/G) has at least
one pack skill** carrying a strand-level `standard_ref`. It does NOT mean:

- every expectation has a dedicated skill — one pack skill like `DC4.NF.FRACTIONS`
  covers all seven `4.NF.*` expectations;
- the pack's scope matches the expectation's scope — strand-level reference is a
  coarse filter, not a scope check;
- any mapping is verified — all 126 remain `REPOSITORY_EXISTING_UNVERIFIED`.
